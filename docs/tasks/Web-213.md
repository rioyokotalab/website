# Web-213 — Change-triggered accessibility and source-integrity sampling

## Status

Pending the next material content/template change or a bounded quarterly
manual checkpoint. This is local/manual work and adds no recurring hosted
workflow.

## Acceptance

Sample representative EN/JP pages with keyboard and one assistive technology,
verify external factual links against primary sources, and record only
actionable regressions. Automated checks remain necessary but do not establish
full accessibility conformance. Reuse local offline/browser gates and publish
only with the normal site task that triggered the sample.

Use W3C [WCAG-EM 2.0](https://www.w3.org/TR/wcag-em-2/) and
[sustaining-accessibility guidance](https://www.w3.org/WAI/planning-and-managing/sustain/)
rather than inventing a site-specific conformance claim.

## Non-authority

This task does not independently authorize deployment, factual content edits,
hosting changes, credentials, or a recurring GitHub Actions workflow.
